SPECIFICATION

About Project

Academic Sports Analytics & Machine Learning Engineering Documentation

Project Overview

Project Title: Match Outcome Prediction Using Logistic Regression and Random Forest
Subtitle: Sports Analytics using Logistic Regression and Random Forest
Purpose:

Predict sports match outcomes using historical performance-related features, including scoring averages, seasonal win rates, goal scoring metrics, composite player performance indices, and home/away venue factors.

Target Format:
Target 1 = Team A Wins Target 0 = Team A Loses

Machine Learning Algorithms

Logistic Regression

Supervised linear classifier with StandardScaler preprocessing. Optimized with L2 regularization to find the optimal maximum-likelihood decision boundary across 47 dimensions.

Random Forest Classifier

Non-linear ensemble learning technique aggregating 200 de-correlated decision trees. Leverages bootstrapping and random subspace feature selection for robust predictive variance reduction.

Core Technology Stack

FastAPI & Uvicorn Backend Server
Scikit-learn Model Inference
Joblib Model Serialization
Pandas & NumPy Data Preprocessing
Matplotlib & Seaborn Model Training & Visuals
HTML5 / Vanilla CSS / JS Modern Dashboard UI

Preprocessing & Feature Vector Architecture

The trained inference pipeline translates raw match parameters into a 47-dimensional feature vector:

  • 8 Numerical Metrics: Avg Score, Win Rate, Avg Goals, Player Performance (both teams)
  • 18 Team A One-Hot Columns: Filtered indicator variables with first-category baseline drop
  • 19 Team B One-Hot Columns: Opponent indicator variables with first-category baseline drop
  • 2 Venue One-Hot Columns: Home and Neutral venue indicators (Away as baseline)
  • Feature Scaler: Applied strictly to Logistic Regression vector; raw DataFrame fed to Random Forest
